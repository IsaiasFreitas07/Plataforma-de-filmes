

Projeto desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos.

## Sobre o projeto

A aplicação permite trabalhar com informações de filmes e séries, utilizando conceitos fundamentais da linguagem Java.

## Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Programação Orientada a Objetos
- Git
- GitHub

## Estrutura do projeto

- `Principal.java` — classe principal da aplicação
- `Filme.java` — representação de filmes
- `Serie.java` — representação de séries
- `Titulo.java` — classe base para filmes e séries

## Objetivo

Projeto desenvolvido para fins de estudo e prática de Java, com foco em orientação a objetos, classes, herança e organização de código.
